Repo apt de santiagofr1

Paquetes .deb de mis proyectos open source, firmados y actualizados en cada release.

Agregarlo (una sola vez)

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://santiagofr1.github.io/apt/key.asc | sudo gpg --dearmor -o /etc/apt/keyrings/santiagofr1.gpg
echo "deb [signed-by=/etc/apt/keyrings/santiagofr1.gpg] https://santiagofr1.github.io/apt stable main" | sudo tee /etc/apt/sources.list.d/santiagofr1.list
sudo apt update

Paquetes

  • rtop: monitor del sistema (TUI y GUI). sudo apt install rtop
  • opennote: apuntes a mano con lápiz, sin cuentas ni nube. sudo apt install opennote
  • claude-sesiones: comando ses para listar, borrar, restaurar y limpiar sesiones de Claude Code. sudo apt install claude-sesiones

Después, sudo apt upgrade trae las versiones nuevas.
